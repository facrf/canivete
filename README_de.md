# Dschungelmesser 🪓

Ein offline, leichtes und schnelles Tool zur Bild- und PDF-Verarbeitung, in Go geschrieben.

## Funktionen
- Weißen Hintergrund entfernen.
- Zuschneiden und Größe ändern.
- Formate konvertieren (PNG, JPG, BMP).
- JPG-Bilder komprimieren.
- Farbpalette extrahieren.
- QR-Codes generieren und lesen.
- PDF-Tools: zusammenführen, teilen, optimieren, schützen und Bilder extrahieren.
