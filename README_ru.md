# Нож для джунглей 🪓

> Лёгкий, автономный и быстрый веб-инструмент для обработки изображений и PDF.  
> Написан на Go. Контейнер включает `librsvg` для SVG и `poppler-utils` для растеризации PDF.

---

## ✨ Возможности

| Категория | Инструменты |
|-----------|-------------|
| 🖼️ **Изображение** | Удаление фона, интерактивная обрезка, изменение размера, конвертация (PNG/JPG/BMP), сжатие |
| 🎨 **Цвета** | Извлечение цветовой палитры (HEX) |
| 📄 **PDF** | Изображения → PDF, объединение PDF, разделение PDF, оптимизация, защита паролем |
| 🔁 **Конвертация** | PDF → Изображения, SVG → PNG |
| 📱 **QR-код** | Создание и декодирование QR-кодов и штрих-кодов |

## 🚀 Развёртывание

### Docker

Используйте файл [`docker-compose.yml`](docker-compose.yml) в Portainer → Stacks.
