# Нож для джунглей 🪓

Легкий, автономный и быстрый инструмент для обработки изображений и PDF на Go.

## Функции
- Удаление белого фона.
- Обрезка и изменение размера.
- Конвертация форматов (PNG, JPG, BMP).
- Сжатие JPG.
- Извлечение цветовой палитры.
- Генерация и чтение QR-кодов.
- Инструменты PDF: объединение, разделение, оптимизация, защита и извлечение.
