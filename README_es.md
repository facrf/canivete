# Navaja de la Selva 🪓

Una herramienta offline, ligera y rápida para procesamiento de imágenes y PDF, escrita en Go.

## Funciones
- Eliminar fondo blanco.
- Recortar y redimensionar.
- Convertir formatos (PNG, JPG, BMP).
- Comprimir JPG.
- Extraer paleta de colores.
- Generar y leer códigos QR.
- Herramientas PDF: unir, dividir, optimizar, proteger y extraer imágenes.
